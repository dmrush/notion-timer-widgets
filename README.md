## 🛠️ URL Query Parameters Reference

You can customize any `https://timerbox.net/embed` URL using query parameters:

* `m` — Minutes (`1` to `180`, e.g., `m=25`)
* `s` — Optional seconds (`0` to `59`)
* `mode` — `disc` (Visual shrinking pie clock) or `digital` (Large tabular numbers)
* `color` — Hex color without `#` (`10b981`, `ef4444`, `0ea5e9`, `8b5cf6`, `f59e0b`, `f43f5e`)
* `theme` — `dark` (`#0f172a`) or `light` (`#f8fafc`)
* `sound` — `true` (chime on completion) or `false` (silent)
* `title` — Custom header label (e.g., `title=Reading+Sprint`)
